# Causal Feature Set Construction



This stage constructs the core causal sets and causal sets enhanced by the addition of EAA variables required to evaluate their predictive performance.





### Input


* `data/causal_methylation_inputs/dmr_matrix.csv`
* `data/methylation/test_dmr_matrix.csv`
* `data/metadata/test_metadata.csv`
* `data/eaa/train_eaa.csv`
* `data/eaa/test_eaa.csv`




### Output



* `data/classification/train_c0.csv`
* `data/classification/test_c0.csv`
* `data/classification/train_c1.csv`
* `data/classification/test_c1.csv`




### Execution



Run the stage driver:



```bash

python run_causal_feature_set_construction.py

```



Or run the full project pipeline from code/:



```bash

python main.py

```





### Structure



|**Order**|**Module**|**Description**|
|-|-|-|
|01|`construct_causal_sets.py`|Functions to construct the core causal sets and enhanced causal sets|
|02|`run_causal_feature_set_construction.py`|Stage driver for the entire causal feature set construction workflow|





### Workflow



1. Construct the core causal test set using the features in the core causal training set (`dmr_matrix.csv` used as an input for the DMR-level causal discovery)
2. Construct the enhanced causal training and test sets by merging the core causal sets with the EAA data





#### Notes



* Sample ordering is preserved throughout preprocessing via the `sample_id` column until metadata and methylation matrices are merged for model training.
* All datasets generated by this stage are intended solely as inputs for the downstream classification stage, with the exception of `train_c0.csv` which is also used as the input for the DMR-level causal discovery as `data/causal_methylation_inputs/dmr_matrix.csv`.
