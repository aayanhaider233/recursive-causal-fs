# Basline Construction



This stage constructs the statistical and SHAP-derived baseline datasets required for the comparison of the classification performances.





### Input



* `data/methylation/train_dmr_matrix.csv`
* `data/methylation/test_dmr_matrix.csv`
* `data/metadata/train_metadata.csv`
* `data/metadata/test_metadata.csv`
* `data/eaa/train_eaa.csv`
* `data/eaa/test_eaa.csv`



### Output


* `data/classification/train_s0.csv`
* `data/classification/test_s0.csv`
* `data/classification/train_s0_prime.csv`
* `data/classification/train_s1_lr.csv`
* `data/classification/test_s1_lr.csv`
* `data/classification/train_s1_rf.csv`
* `data/classification/test_s1_rf.csv`





### Execution



Run the stage driver:



```bash

python run_baseline_construction.py

```



Or run the full project pipeline from code/:



```bash

python main.py

```





### Structure



|**Order**|**Module**|**Description**|
|-|-|-|
|01|`variance_filter.py`|Filter DMRs by variance|
|02|`correlation_network_pruning.py`|Filter DMRs by constructing correlation networks|
|03|`construct_statistical_baseline.py`|Driver for statistical baseline construction|
|04|`pre_shap_processing_training.py`|Top DMRs by variance selection and subsequent model training for SHAP computation|
|05|`shap_computation.py`|Function to compute SHAP values and rank features|
|06|`shap_ranking_filter.py`|Top DMRs by SHAP ranking selection|
|07|`construct_shap_baseline.py`|Driver for SHAP-derived baseline construction|
|08|`run_baseline_construction.py`|Stage driver for entire baseline construction workflow|


### Workflow



1. DMR variance filtering 
2. DMR correlation network pruning 
3. Final statistical baseline dataset construction
4. Top DMRs by variance selection 
5. ML model training for SHAP computation
6. SHAP computation for each model
7. Feature ranking by mean SHAP value
8. Top DMRs by SHAP ranking selection
9. Final SHAP-derived baseline dataset construction




#### Notes

* Variance filtering, correlation network pruning, and SHAP feature selection are fit **only on the training set**. The resulting feature subsets are then applied unchanged to the corresponding test set to prevent information leakage.
* SHAP feature importance is computed separately for the Logistic Regression and Random Forest models, producing distinct SHAP-derived baseline datasets (`s1_lr` and `s1_rf`).
* The statistical baseline (`s0`) follows the feature-selection procedure reported in the accompanying manuscript and is intended as the primary non-causal comparison baseline.
* Sample ordering is preserved throughout preprocessing via the `sample_id` column until metadata and methylation matrices are merged for model training.
* All datasets generated by this stage are intended solely as inputs for the downstream classification stage.
