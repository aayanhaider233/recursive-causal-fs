# Methylation Probe Annotations



The following files are required for filtering Illumina HumanMethylation450 probes and for probe annotations.



|**Required file**|**Purpose**|
|-|-|
|`humanmethylation450_15017482_v1-2.csv`|Illumina HumanMethylation450 manifest|
|`48639-non-specific-probes-Illumina450k.csv`|Cross-reactive probe list|
|`HumanMethylation450_15017482_v.1.1_hg19_bowtie_multimap.txt`|Multi-mapping probe list|





#### Sources



* Illumina HumanMethylation450 manifest (Illumina release)
* Chen et al. (2013) cross-reactive probe annotations
* Bowtie multi-mapping probe annotations for HumanMethylation450





#### Note



* Place the downloaded files in `annotations/methylation/`
